# -The-Cat-From-The-East-
Primer repositorio de trabajo. Seguimiento del juego

Nombre del juego> "The Cat From The East"
> Soft-Platformer / Acción
> Plataforma: PC

Mecánica Principal:
Souls-like, no se proporciona mucho al jugador al principio. Cuanto más avanze el jugador, más mecánicas se le conceden (Ej: Al matar a un jefe, la botella que tenía se le da al jugador y esta le permite dar un doble salto)

Motor de desarrollo:
Unity
